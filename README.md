## Samples

See [the sample guide](docs/samples.md) for the current sample projects:

- `Nesi.UI.Demo` — multi-window component and asset showcase.
- `Nesi.UI.SimpleDemo` — basic controls, layouts, and custom draw-list examples.
- `Nesi.UI.LoaderDemo` — simulated loader-to-login UI flow.
